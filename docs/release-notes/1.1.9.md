# Ohbee Editor 1.1.9

Released 2026-08-25 · macOS 13 Ventura or later · Build 14

A correctness and data-safety release. No new features. Everything here came out of a full audit of
the project documentation and the source, and most of it protects text you have not saved yet.

## Why upgrade

If you keep unsaved notes in Ohbee Editor, this release removes three ways you could have lost them
and one way a redacted copy could still have leaked part of a secret.

## Your text is safer

- **Notes survive the sandbox upgrade.** The migration that carries your notes from a pre-sandbox
  install into the new sandboxed app resolved the wrong home directory, so it never ran. Upgrading
  could silently start you with an empty workspace. It now finds and copies the old state.
- **A damaged session file no longer discards your notes.** Previously an unreadable session was
  treated as "no session": the app opened with one blank note and then deleted the stored text of
  your large unsaved notes. Now the unreadable file is set aside as `session.corrupt-<timestamp>.json`,
  any note text that no longer has a readable index is moved to a `Recovered Note Text <timestamp>`
  folder that cleanup never touches, and the status bar tells you both locations.
- **A session written by a newer build is recognized as such**, instead of being reported as corrupt.
- **Closing several tabs with unsaved changes offers Save All.** Before, that warning only offered
  Close Without Saving or Cancel — there was no way to keep the changes. Unsaved notes go through
  Save As, and cancelling any save aborts the whole close so nothing is discarded.
- **Save refuses to write back to a file whose access was revoked**, pointing you at Save As instead,
  and a successful save now clears that state so Save All stops skipping the tab.

## Privacy

- **Masked output no longer keeps part of your secrets.** Safe Share used to write
  `sk_l***IjKl` and `john***.com`, preserving the first and last four characters and the exact
  length. Copy Masked and Apply Mask now write a fixed `***REDACTED***` placeholder.
- **Safe Share stops flagging your logs.** Timestamps like `2026-05-15 12:30:45`, IP addresses,
  version strings, order numbers, dates, and numeric columns are no longer reported as phone
  numbers — which also means Apply Mask no longer rewrites them.
- **Review rows show the line of each finding**, so two findings of the same kind can be told apart
  before you choose what to mask.

## Text tools

- **Sorting a file that ends with a newline no longer moves a blank line to the top** and no longer
  drops the final newline. The same fix applies to Trim Whitespace, Trim Trailing Spaces, Remove
  Empty Lines, and Remove Duplicate Lines.
- **CRLF files keep their final line ending.** The check for a trailing newline was blind to `\r\n`.

## Search

- **Regex mode accepts ordinary patterns again.** Non-capturing groups `(?:a|b)`, lookarounds
  `\d+(?=px)`, quantified groups `(ab)+`, and bounded repetition such as `([0-9]{1,3}\.){3}[0-9]{1,3}`
  all work. Nested unbounded quantifiers such as `(a+)+` and `((a+))+` and pattern backreferences are
  still refused, and pathological matching is still stopped on a deadline.
- **Highlights and the match counter can no longer disagree**, and highlight ranges are clamped to
  the live text before drawing, which removes a crash path.

## Under the hood

- Added the `com.apple.security.files.bookmarks.app-scope` entitlement. Without it the sandboxed
  build could not create the bookmarks that keep file-backed tabs, Open Recent, and Reopen Closed
  File working across launches. Failures are now logged and reported instead of ignored.
- File open, save, and tab-close commands have one shared implementation behind both the menu bar
  and the in-window controls.
- Self-test suite grew from 87 to 107 tests.

## Still local-first

No account, no cloud sync, no telemetry, no analytics, no remote AI calls, no background upload.
Document text never leaves the Mac. The only network-adjacent action remains Report Issue, which you
trigger yourself and which sends no document text.

## Known limitations

- Safe Share stays best-effort. It helps you notice likely sensitive text; it does not guarantee
  complete secret detection.
- Phone numbers written with dots (`555.123.4567`) are not detected. Excluding `.` is what keeps IP
  addresses and version strings safe in logs.
- Closing several unsaved notes at once opens one Save panel per note, in sequence.
- Saving a file that was opened as UTF-16 or another non-UTF-8 encoding still writes UTF-8.

## Verifying this build

The sandbox migration and the bookmark entitlement can only be exercised by a signed, sandboxed
bundle. Build it with `make install DEVELOPER_ID="Developer ID Application: You (TEAMID)"` and run
the sandbox items in `docs/release-checklist.md`. An unsigned `make bundle` artifact does not have
App Sandbox active and cannot confirm those two fixes.
